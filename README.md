# Asignatura: Programación

Este repositorio contiene las prácticas, proyectos y ejercicios resueltos de la asignatura de **Programación** en **1º DAM - IES Pablo Picasso (Málaga)**.


## 🛠️ Tecnologías y Lenguajes
* **Lenguaje Principal:** Java
* **Entorno / IDE:** Eclipse
* **Herramientas:** Git, GitHub

## 📂 Contenido

* Conceptos básicos, variables y condicionales.
* Estructuras de control repetitivas.
* Programación Orientada a Objetos (Clases, Herencia).
